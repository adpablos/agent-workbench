# Workbench

This folder coordinates agent work across repositories and information sources. It is not a Git
repository.

Before acting, read these files in full; do not rely on an earlier reading:

1. `core/OPERATING.md`: the operating contract.
2. `private/POLICY.md`: approved local rules and preferences.

Read `private/workspace.json` before accessing any source or path, and `private/INDEX.md` when
resuming work. If `core/OPERATING.md` cannot be read, report that and do nothing else. If
`private/POLICY.md` or `private/workspace.json` is missing or still shows a placeholder approval
date, the workbench is being set up: only continue the setup in `core/README.md`.

Organizational requirements and the instructions of each repository you work in remain binding.
Report conflicts instead of choosing between them.
