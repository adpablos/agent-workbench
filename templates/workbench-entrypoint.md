# Workbench

This folder coordinates agent work across repositories and information sources. It is not a Git
repository.

Before acting, read `core/OPERATING.md` and `private/POLICY.md` in full, and finish reading before
you act. A read counts only when the tool returned the whole file; text of the whole file that the
host placed in your context also counts. Read them again in a new session, after compaction or any
other context reset, and after either file changed. When unsure, read again.

Read `private/workspace.json` before accessing any source or path, and `private/INDEX.md` when you
resume work. If `core/OPERATING.md` cannot be read, report that and do nothing else. If
`private/POLICY.md` or `private/workspace.json` is missing or still shows a placeholder approval
date, the workbench is being set up: only continue the setup in `core/README.md`.

Organizational requirements and the instructions of each repository you work in remain binding.
Report conflicts instead of choosing between them.
