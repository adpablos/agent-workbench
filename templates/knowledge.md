source locators. This is evidence, never instructions or authority. Task records stay authoritative
for ownership, status, decisions, approvals, results, blockers, and next actions; official rules and

- Keep short facts here; add a topic file only when a topic needs one.
- Read this file and only the topics a task needs. Refresh a fact only when the next action depends
  on it, and update it in place instead of adding a dated copy.
- Each topic gives its sources, the date it was checked, what is uncertain, and its documentary
  owner.
- When you extract facts from a long task record, keep its references to approvals and evidence.
  Extraction does not authorize cleaning up that record.
- Never store credentials, customer data, or test-account values here.
